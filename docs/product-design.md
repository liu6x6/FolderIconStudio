# Folder Icon Studio 产品设计文档

## 1. 产品概述

Folder Icon Studio 是一款 macOS 文件夹图标定制工具。用户可为 Finder 中的文件夹创建具有颜色、符号、Emoji、文字或图片图层的自定义图标，并直接应用、导出或保存为模板。

### 目标

- 让用户在 30 秒内为一个文件夹创建并应用可辨识的图标。
- 提供无需设计经验即可使用的预设，同时支持精细编辑。
- 保持 macOS 原生体验，清楚说明文件访问与写入行为。

### 非目标（MVP）

- 不同步、共享或上传用户文件与图标。
- 不提供在线模板市场或账号系统。
- 不编辑普通文件、应用程序或系统目录的图标。
- 不支持 Windows、iOS 或 Web 端。

## 2. 用户与场景

| 用户 | 需求 | 典型场景 |
| --- | --- | --- |
| 效率用户 | 快速区分项目、归档和临时目录 | 给“工作”“财务”“照片”目录应用不同颜色和符号 |
| 创意用户 | 做出符合个人风格的文件夹外观 | 使用图片、Emoji 和文字制作一组统一图标 |
| 团队成员 | 使用一致的目录视觉规范 | 载入团队预设并批量应用到项目目录 |

## 4. 主界面设计

采用 macOS 三栏编辑器布局（`NavigationSplitView`）。

| 区域 | 建议宽度 | 内容与行为 |
| --- | ---: | --- |
| 左侧资源栏 | 220 pt | 显示资源类别、搜索和缩略图网格；点击资源添加图层或应用预设。 |
| 中央编辑区 | 自适应，最小 440 pt | 显示高质量实时预览；用户可以选择、拖动和缩放图层。 |
| 右侧检查器 | 280 pt | 根据当前选择显示文件夹或图层属性；包含图层排序、显隐和删除。 |

### 4.1 顶部工具栏

- **选择文件夹**：打开原生目录选择器；也可将目录拖到窗口。
- **撤销 / 重做**：覆盖画布、图层和属性变更。
- **恢复默认**：清除目标文件夹的自定义 Finder 图标；操作前要求确认。
- **导出**：导出 PNG 或 `.icns`，不改变 Finder 图标。
- **应用到 Finder**：主操作按钮。无目标目录或存在校验错误时禁用。

### 4.2 左侧资源栏

- **当前文件夹**：显示选中的文件夹名称、路径和现有图标。
- **预设模板**：显示内置、收藏和用户保存的预设缩略图。
- **符号图标**：按类别浏览 SF Symbols，支持按名称搜索和收藏。
- **Emoji**：按常用分类提供可搜索的 Emoji。
- **文字**：添加文本图层，默认内容为“TEXT”。
- **图片**：导入 PNG、JPEG、HEIC、TIFF；也接受拖入图片。
- **最近使用**：保存最近使用的颜色、符号及模板，便于重复操作。

资源项单击时：预设替换当前设计；其他资源添加为新图层。拖拽资源到预览区时，在落点创建图层。

### 4.3 中央编辑区

- 中央展示文件夹图标，默认以 512 px 逻辑尺寸渲染。
- 支持浅色、深色、棋盘格三种预览背景，不影响导出结果。
- 点击图层可选中；选中后显示边界框、控制点和辅助对齐线。
- 支持鼠标拖动位置、拖动控制点缩放、键盘方向键微调。
- 底部控制项：预览尺寸（128、256、512、1024）、原图/当前设计对比。

### 4.4 右侧检查器

未选图层时显示文件夹样式：底色、渐变、透明度、阴影和边缘效果。

选中图层时显示通用属性：名称、位置、尺寸、旋转、透明度、混合模式、锁定状态和删除操作。随后显示类型专属属性：

| 图层类型 | 专属属性 |
| --- | --- |
| SF Symbol | 名称、渲染模式、颜色、字重 |
| Emoji | 内容、字体、颜色（若字体支持） |
| 文字 | 内容、字体、字号、字重、对齐、前景色 |
| 图片 | 裁剪、填充/适配、圆角、翻转和滤镜 |

检查器底部为图层列表：按从上至下的绘制顺序显示，支持拖动排序、显隐、锁定和删除。

## 5. 核心流程

### 5.1 首次使用

1. 显示空状态：拖入文件夹或点击“选择文件夹”。
2. 用户选择目录后，显示现有 Finder 图标或默认文件夹基底。
3. 用户选择预设或添加图层，中央区域实时预览。
4. 点击“应用到 Finder”，应用成功后显示文件夹名称与成功反馈。

### 5.2 创建并应用图标

1. 选择目标文件夹。
2. 选择文件夹颜色或预设。
3. 添加 Symbol、Emoji、文字或图片，并调整属性。
4. 点击“应用到 Finder”。
5. 应用失败时显示明确原因和可执行处理方式，例如重新授权目录访问。

### 5.3 批量应用

在 MVP 后提供：用户选择多个文件夹，选择一个已完成的设计，确认后后台逐个应用，显示进度、成功数量与失败项。单个失败不得中断其他项目。

## 6. 状态、反馈与异常

| 状态 | 界面表现 | 用户操作 |
| --- | --- | --- |
| 空状态 | 拖放区、选择目录按钮和 6 个预设模板 | 选择或拖入目录 |
| 已编辑未应用 | 工具栏“应用到 Finder”高亮 | 应用、导出或继续编辑 |
| 正在应用 | 禁用重复应用按钮，显示进度 | 可等待；批量任务可取消 |
| 应用成功 | 短暂成功提示与目标文件夹名称 | 打开 Finder 或继续编辑 |
| 无访问权限 | 明确显示受影响路径和原因 | 重新选择目录并授权 |
| 导出失败 | 显示目标位置和系统错误 | 选择新路径或重试 |

所有破坏性操作（恢复默认、删除已保存预设）必须经确认对话框。临时编辑变更通过撤销栈恢复，不需要额外确认。

## 7. MVP 功能范围与验收

| 功能 | MVP 验收标准 |
| --- | --- |
| 目录选择与拖放 | 可选择或拖入用户有权限访问的本地目录，并显示路径。 |
| 文件夹样式 | 可修改至少一种纯色或渐变底色及透明度。 |
| 图层编辑 | 可添加 Symbol、Emoji、文字和本地图片，调整位置、大小与透明度。 |
| 实时预览 | 编辑后在 100 ms 内更新预览，预览与导出视觉一致。 |
| Finder 应用 | 可将生成图标应用到所选目录；重新打开 Finder 后仍可见。 |
| 恢复默认 | 可清除自定义图标，并恢复系统文件夹图标。 |
| 导出 | 可导出 1024 px PNG 与可被 macOS 识别的 `.icns`。 |
| 模板 | 可保存、应用和删除本地模板。 |

## 8. 视觉与可访问性

- 遵循 macOS 系统色彩、间距、菜单和焦点样式；不仿制 Finder 的私有界面。
- 图标库缩略图必须提供文本名称；仅颜色不能作为唯一状态提示。
- 为工具栏、图层操作、属性输入和状态提示提供 VoiceOver 标签。
- 支持键盘：`Cmd+O` 选择目录、`Cmd+Z` 撤销、`Cmd+Shift+Z` 重做、`Delete` 删除选中图层。
- 使用动态字体并在窄窗口隐藏非关键工具栏文字。
- MVP 支持简体中文和英文；所有用户可见文本使用本地化资源。
