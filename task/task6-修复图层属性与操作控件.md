# 任务 6：修复图层属性与操作控件

## 目标

1. 多彩 Symbol 也可使用用户选择的颜色，生成协调的多色 palette。
2. 图层不透明度实际影响渲染，并以 0–100% 显示和编辑。
3. 旋转以 0–360° 显示和编辑。
4. 修复图层上移/下移操作，并将层级和删除操作改为图标按钮。

## 实施步骤

1. 为多彩 Symbol 从用户主色生成亮色与暗色 palette，替代固定系统多彩色。
2. 将图层渲染改为显式图像/文本 alpha，增加不透明度输出差异测试。
3. 将属性面板滑块映射为用户可见的百分比与角度，并显示精确数值。
4. 使用稳定的数组移除/插入实现层级移动。
5. 将上移、下移、删除替换为箭头和废纸篓图标，保留工具提示与无障碍标签。

## 验收标准

- 单色与多彩 Symbol 均能响应颜色选择器。
- 不透明度为 0% 时图层不可见，100% 时完全可见。
- 旋转可设置到 0–360° 并显示当前度数。
- 上移/下移改变渲染层级；操作按钮只显示图标。

## 完成结果

- 多彩模式使用用户主色、亮色和暗色组成的 palette；“Symbol 颜色”在两种渲染模式下都可编辑。
- 图层图片/Symbol 使用显式 alpha 绘制，文本前景也会应用 alpha；不透明度面板显示并编辑 0–100%。
- 旋转面板显示并编辑 0–360°。
- 层级移动改为数组移除后插入，确保操作改变图层顺序。
- 下移、上移、删除已改为箭头和废纸篓图标，含工具提示与无障碍标签。
- `swift test` 通过 17 项测试；Xcode GUI App 构建成功。
