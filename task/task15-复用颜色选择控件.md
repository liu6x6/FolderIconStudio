# 任务 15：复用颜色选择控件

## 目标

将颜色选择提取为通用控件，并在文件夹、文字和 Symbol 属性中复用。

## 实施步骤

1. 创建接收 `ColorValue` 绑定的通用颜色选择控件。
2. 使控件可选地显示颜色预设、屏幕取色操作和 Hex 值。
3. 将文件夹、文字和 Symbol 属性替换为该控件。

## 验收标准

- 三种属性使用同一颜色选择基础控件。
- 文件夹仍可使用预设颜色、屏幕取色与 Hex 显示。
- 文字与 Symbol 颜色仍实时更新渲染。

## 完成结果

- 已新增 `ColorSelectionControl` 通用控件，统一处理 `ColorValue` 绑定与系统颜色选择器。
- 文件夹配置启用预设、屏幕取色和 Hex 值；文字与 Symbol 配置使用同一基础控件。
- `swift test` 通过 19 项测试，Xcode Debug App 构建成功。
