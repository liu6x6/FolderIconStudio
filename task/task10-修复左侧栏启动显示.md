# 任务 10：修复左侧栏启动显示

## 目标

确保 App 首次打开时左侧资源栏内容完整可见；当窗口高度不足时，用户仍可滚动访问所有内容。

## 实施步骤

1. 检查资源栏的滚动容器、内容尺寸和侧栏宽度约束。
2. 调整启动布局，固定启动时展开的侧栏状态，并提供足够的栏位与窗口最小宽度。
3. 构建 GUI App，确认布局可正常启动。

## 验收标准

- 首次启动时左侧栏的顶部内容正确显示。
- 内容超出可用高度时可通过滚动访问。
- 左侧栏维持原有内容与交互。

## 完成结果

- 左侧栏在首次启动时固定为展开状态。
- 侧栏宽度调整为 260–360pt（默认 300pt），避免字体、控件与 Symbol 内容被横向裁切。
- 窗口最小宽度调整为 1020pt，并使用平衡的双栏布局，保证左栏与右侧属性栏同时显示时仍有充足空间。
- Xcode Debug App 构建成功。
