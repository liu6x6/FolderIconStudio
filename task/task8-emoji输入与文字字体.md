# 任务 8：Emoji 输入与文字字体

## 目标

1. 选中 Emoji 图层时，点击内容输入框可打开 macOS 系统 Emoji 与符号面板，并将选中的 Emoji 输入到当前图层。
2. 选中文字图层时，可选择 macOS 已安装的字体家族，并在预览、导出和模板中保持一致。

## 实施步骤

1. 使用 AppKit 文本字段封装 SwiftUI 输入控件，在其获得焦点时调用系统 Character Palette。
2. 将 Emoji 内容与该原生字段双向绑定。
3. 为 `TextLayer` 增加可编码的字体家族字段，并为旧模板提供系统字体回退。
4. 在文字属性中提供已安装字体家族的选择器。
5. 渲染文字时按选中的字体家族解析 `NSFont`。
6. 增加模板字体编解码测试，构建 GUI App。

## 验收标准

- 点击 Emoji 内容输入框会打开 macOS Emoji 与符号面板。
- 从面板插入的 Emoji 立即更新图层。
- 文字图层可选择已安装字体，预览和导出使用该字体。
- 旧模板未存字体时仍用系统字体正确加载。

## 完成结果

- 新增 `EmojiTextField.swift`；Emoji 内容字段获得焦点时会打开 macOS 系统 Emoji 与符号面板，并继续作为字符插入目标。
- `TextLayer` 现在持久化字体家族；旧模板缺少该字段时回退为系统粗体。
- 文字图层属性区新增已安装字体家族选择器，渲染、PNG/ICNS 导出和模板均使用同一字体配置。
- `swift test` 通过 18 项测试；Xcode GUI App 构建成功。
