# 任务 9：文字字体搜索、样式与颜色

## 目标

1. 文字图层可通过搜索框快速筛选已安装的字体家族。
2. 文字图层可选择字重和斜体样式。
3. 文字图层可独立选择颜色，并在预览、导出和模板中保持一致。

## 实施步骤

1. 扩展 `TextLayer` 的可编码字体样式与颜色属性，并保持旧模板兼容。
2. 在文字属性区加入字体搜索、字重、斜体和颜色控件。
3. 使用字体管理器按字体家族、字重与斜体解析字体。
4. 在文字图层渲染路径应用文字颜色。
5. 增加模型持久化与渲染覆盖测试，并运行测试和 GUI 构建。

## 验收标准

- 输入关键词后，字体列表只显示匹配的已安装字体。
- 字重与斜体即时更新文字预览和导出结果。
- 文字颜色即时更新文字预览和导出结果。
- 新字体样式与颜色可保存；旧模板仍可打开。

## 完成结果

- 文字属性区新增字体搜索框；字体列表会按已输入关键词即时筛选。
- 新增常规、中等、半粗、粗体、特粗五种字重，以及斜体开关。
- 新增独立的文字颜色选择器；颜色会作用于预览、PNG/ICNS 导出和 Finder 图标。
- 字重和斜体会保存到模板；缺少新字段的旧模板继续使用粗体、非斜体的默认样式。
- `swift test` 通过 19 项测试；Xcode Debug App 构建成功。
