# 任务 22：预览与模板渲染缓存

## 目标

缓存图标渲染结果，避免 SwiftUI 重绘时重复生成预览和模板缩略图。

## 实施步骤

1. 为 `IconDocument` 建立稳定的渲染缓存键。
2. 增加线程安全的图像缓存服务。
3. 让预览和模板缩略图通过缓存服务获取图像。
4. 添加缓存命中与失效测试。

## 验收标准

- 相同文档和尺寸仅渲染一次。
- 文档改变后会生成新图像。
- 预览与模板缩略图外观不变。

## 完成结果

- `IconRenderer` 已根据稳定编码的文档内容和像素尺寸缓存渲染图像。
- 预览和模板缩略图继续通过同一渲染器自动受益于缓存。
- 已新增缓存命中与文档变更失效测试；`swift test` 通过 21 项测试，Xcode Debug App 构建成功。
