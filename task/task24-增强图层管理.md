# 任务 24：增强图层管理

## 目标

支持图层排序、复制、锁定、隐藏和缩略图展示。

## 实施步骤

1. 扩展图层模型的锁定与可见状态，并兼容旧模板。
2. 在渲染器中跳过隐藏图层。
3. 为图层列表加入类型缩略标识、复制、锁定、显示切换和排序操作。
4. 添加模型与渲染测试。

## 验收标准

- 隐藏图层不参与渲染，锁定图层不可编辑。
- 可复制图层，并使用上移/下移调整顺序。
- 图层列表可显示缩略图和状态。

## 完成结果

- `LayerTransform` 已持久化可见与锁定状态，并兼容旧模板的默认值。
- 渲染器会跳过隐藏图层；锁定图层不能被编辑、移动、复制或删除。
- 图层操作区新增复制、显示切换和锁定切换；图层列表显示类型和状态图标。
- 已新增隐藏渲染、锁定保护测试；`swift test` 通过 24 项测试，Xcode Debug App 构建成功。
