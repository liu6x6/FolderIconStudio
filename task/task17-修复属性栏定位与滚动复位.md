# 任务 17：修复属性栏定位与滚动复位

## 目标

1. 文件夹切换后，右侧属性栏始终从顶部显示。
2. 窗口扩展时，右侧属性栏固定贴在窗口最右侧，多余宽度由中间画布吸收。
3. 预览在中间画布区域保持居中。

## 实施步骤

1. 使用固定右侧栏的水平布局替代会重新分配额外宽度的分栏布局。
2. 为属性栏滚动容器增加顶部锚点。
3. 在文件夹或属性标签切换时将滚动位置复位到顶部。

## 验收标准

- 选择新文件夹后，属性栏内容从顶部开始。
- 拖宽窗口时，右栏右边缘仍贴齐窗口。
- 新增空间只扩展画布区域，预览保持居中。

## 完成结果

- 右侧栏改为固定在水平布局的最右侧，画布获得全部可用的额外宽度。
- 属性栏在切换文件夹或标签时自动滚动回顶部。
- `swift test` 通过 19 项测试，Xcode Debug App 构建成功。
