# 任务 16：文字与 Symbol 颜色预设和取色

## 目标

为文字和 Symbol 图层启用与文件夹一致的颜色预设和屏幕取色功能。

## 实施步骤

1. 为选中文字和 Symbol 图层增加屏幕取色入口。
2. 在两种图层的通用颜色控件中启用预设、取色与 Hex 显示。
3. 确保屏幕取色只更新当前目标图层。

## 验收标准

- 文字和 Symbol 颜色区域显示预设颜色与吸管按钮。
- 选择预设或屏幕颜色后，当前图层立即更新。
- 文件夹取色行为不变。

## 完成结果

- 文字和 Symbol 的颜色控件现已显示 16 个预设色、屏幕吸管和 Hex 值。
- 屏幕取色会分别更新当前选中的文字或 Symbol 图层，不会改变文件夹颜色。
- `swift test` 通过 19 项测试，Xcode Debug App 构建成功。
