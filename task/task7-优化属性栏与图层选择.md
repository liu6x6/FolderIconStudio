# 任务 7：优化属性栏与图层选择

## 目标

1. 移除旋转和不透明度滑块周围难看的分隔黑线。
2. 将旋转范围调整为 0–359°。
3. 隐藏右侧属性栏滚动条，并使其内容区域延伸到右侧窗口边缘。
4. 将上移、下移、删除图标操作放到 Symbol 属性之前。
5. 让整行图层项目都可点击选中，并用背景高亮替代对钩。

## 实施步骤

1. 为滑块的属性行隐藏 Form 分隔线，并将旋转滑块最大值改为 359。
2. 配置右侧 Form 的滚动指示器和边缘尺寸。
3. 抽取图层操作区，调整其在属性栏中的显示顺序。
4. 扩展图层按钮命中区域，并添加选择态背景。
5. 构建 GUI App 并验证滚动、选择与层级操作。

## 验收标准

- 旋转和不透明度属性不显示额外的黑色行分隔。
- 旋转只允许 0–359°。
- 右栏不显示滚动条，内容填充至右边缘。
- 图层操作区显示在 Symbol 属性区之前。
- 点击图层行的任意位置都可以选中，选中时为背景高亮而非对钩。

## 完成结果

- 旋转滑块范围已调整为 0–359°；旋转、不透明度及位置滑块的 Form 行分隔线已隐藏。
- 右侧属性 Form 已隐藏滚动指示器，并继续填充右侧面板的完整宽高。
- 图层操作区已前置到 Symbol 属性之前。
- 图层行移除了对钩，改为全宽可点击区域与背景选中态。
- `swift test` 通过 17 项测试；Xcode GUI App 构建成功。

## 迭代：移除右栏边缘间距

1. 将右栏滚动内容边距设置为零。
2. 移除连续属性区之间的外部间距。
3. 保留属性区内部控件间距，但让属性栏表面贴合窗口上、下、右边。

### 迭代结果

- 右栏 `ScrollView` 的滚动内容边距已设为 0。
- 属性区外部间距已设为 0，使属性栏背景连续贴合窗口边缘。
- Xcode GUI App 构建成功。

## 迭代：重构右侧滚动容器

1. 移除 `Form`，因为其内置滚动条、内容边距和行分隔线无法通过行修饰器彻底移除。
2. 使用 `ScrollView(showsIndicators: false)` 和全宽自定义属性区重建右栏。
3. 将所有现有 Section 改为无系统分隔线的自定义属性区。

### 迭代结果

- 右栏已从系统 `Form` 重构为 `ScrollView(showsIndicators: false)`，不再由系统显示滚动条或预留滚动条空间。
- 新增全宽 `InspectorSection`，替代所有系统 `Section`；系统行分隔线不再存在。
- 内容容器明确填充右侧面板的完整可用宽度与高度。
- `swift test` 通过 17 项测试；Xcode GUI App 构建成功。
