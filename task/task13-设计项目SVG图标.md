# 任务 13：设计项目 SVG 图标

## 目标

为 Folder Icon Studio 创建可缩放的品牌 SVG 图标。

## 设计

- 深蓝至紫色圆角方形底板，对应 macOS App Icon 的视觉比例。
- 蓝色系统文件夹作为核心识别元素。
- 渐变画笔与星光表达图标设计、配色和自定义能力。
- 使用纯 SVG 路径和渐变，不依赖外部字体或位图资源。

## 验收标准

- 图标可在浏览器、GitHub README 和设计工具中直接打开。
- 1024 x 1024 画布可无损缩放，适用于后续导出 macOS App Icon。

## 完成结果

- 已新增 `Assets/FolderIconStudio.svg`，使用 1024 x 1024 的纯矢量图形。
- README 已展示该图标。
- SVG XML 解析与 Git 空白检查通过。
