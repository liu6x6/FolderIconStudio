# 任务 20：优化属性栏与空状态

## 目标

1. 移除右侧属性分区的背景色。
2. 将预设模板移动至左侧栏底部。
3. 将属性标签页顺序调整为“图层”在左、“文件夹样式”在右。
4. 简化未选择文件夹时的中间空状态。

## 实施步骤

1. 移除 `InspectorSection` 的材质背景。
2. 重排侧栏模板分区。
3. 重排属性标签枚举顺序。
4. 用可点击的文件夹加号图标与单行拖放提示替换大号空状态按钮。

## 验收标准

- 右侧栏分区没有灰色背景。
- 预设模板处于左栏最底部。
- 图层标签在左，文件夹样式标签在右。
- 空状态只显示可点击的文件夹加号图标和“拖入文件夹开始设计”。

## 完成结果

- 已移除右侧 `InspectorSection` 的材质背景。
- 预设模板已移动到左栏最底部。
- 属性标签显示顺序为左侧“图层”、右侧“文件夹样式”。
- 未选择文件夹时，中间区域只显示可点击的文件夹加号图标和“拖入文件夹开始设计”。
- `swift test` 通过 19 项测试，Xcode Debug App 构建成功。
