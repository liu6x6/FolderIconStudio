# 任务 23：编辑器撤销与重做

## 目标

为文档编辑操作提供撤销和重做能力。

## 实施步骤

1. 在编辑器 ViewModel 中接入 `UndoManager`。
2. 将文档修改封装为可注册撤销的更新操作。
3. 为常用编辑动作提供工具栏入口。
4. 添加文档状态撤销/重做测试。

## 验收标准

- 图层、颜色、变换和模板应用可撤销及重做。
- 工具栏撤销和重做可用。

## 完成结果

- `EditorViewModel` 已以文档快照自动记录编辑历史，并正确注册撤销/重做的反向状态。
- 工具栏已提供撤销和重做按钮。
- 已新增快照撤销/重做测试；`swift test` 通过 22 项测试，Xcode Debug App 构建成功。
