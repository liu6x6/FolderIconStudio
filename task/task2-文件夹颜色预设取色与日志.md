# 任务 2：文件夹颜色预设、取色与日志

## 目标

1. 提供 10 个适合 macOS 文件夹图标的预设颜色，同时保留颜色选择器的精确自定义能力。
2. 允许用户使用系统取色器从桌面或屏幕任意位置选取颜色。
3. 每次用户选择预设、使用颜色选择器或完成屏幕取色时，都在应用日志输出最终颜色的 Hex 值。

## 实施步骤

1. 为颜色值增加稳定的 RGB Hex 表示，并定义 10 个适合文件夹视觉层次的预设色。
2. 在右侧“文件夹样式”中增加预设色板；点击色板立即应用颜色，并保留现有颜色选择器。
3. 使用 `NSColorSampler` 打开 macOS 系统取色器；调用 Screen Capture 预检与请求 API。
4. 在 App 的 `Info.plist` 生成配置中写入 `NSScreenCaptureUsageDescription`，说明仅在用户主动取色时读取屏幕像素。
5. 使用 `Logger` 输出颜色来源与 `#RRGGBB` 值，避免记录路径或图像等无关隐私信息。
6. 增加颜色格式化与预设数量测试，构建 GUI App 并运行完整测试。

## 验收标准

- 右侧面板显示并可应用 10 个清晰区分、适合文件夹的预设色。
- 用户可通过颜色选择器设置任意最终颜色。
- 点击“从屏幕取色”时按系统要求请求屏幕录制权限；授权后可从屏幕取色。
- 每次颜色变更都在控制台记录来源和准确的 `#RRGGBB`。

## 完成结果

- 已提供 10 个文件夹预设色：海洋蓝、天际蓝、青绿色、森林绿、柠檬黄、琥珀橙、珊瑚红、莓果粉、紫罗兰、石墨灰。
- 色板、系统颜色选择器和系统屏幕取色器都会更新同一个最终颜色；右侧会显示当前 `#RRGGBB`。
- 屏幕取色使用 `NSColorSampler`，并通过 Screen Capture 预检/请求 API 申请 macOS 屏幕录制权限。
- 已配置 `NSScreenCaptureUsageDescription`，说明权限仅用于用户主动发起的取色。
- 已使用 `Logger` 记录预设、颜色选择器与屏幕取色的来源和最终 Hex 值。
- `swift test` 通过 8 项测试；Xcode GUI App 构建成功。

## 迭代：修复取色与颜色预览

1. 将取色入口改为仅显示吸管图标，并提供辅助说明。
2. 移除会阻断系统取色器的主动屏幕录制预检，直接调用 macOS 系统 `NSColorSampler`。
3. 将文件夹上色从低透明度覆盖改为保留原始亮度、替换颜色的混合模式，使红色等预设在预览中产生明确颜色变化。
4. 将预设颜色扩充至 16 个，并增加对应测试。

### 迭代结果

- “从屏幕取色”已改为仅显示吸管图标，悬停提示与无障碍标签仍保留完整说明。
- 已移除会使授权对话框替代取色操作的主动屏幕录制请求；点击吸管后直接打开 macOS 系统取色覆盖层，取消不会改变颜色。
- 文件夹颜色改为 `.color` 混合模式：保留系统文件夹的亮暗和材质，同时完整替换色相与饱和度；红色、蓝色等预设会产生明确不同的预览。
- 预设色板已从 10 色扩展为 16 色。
- 新增红蓝渲染输出差异回归测试；`swift test` 通过 9 项测试。

## 迭代：限制文件夹颜色的渲染范围

1. 使用系统文件夹底图的 alpha 蒙版裁剪颜色混合区域。
2. 确保图标透明背景不参与颜色混合。
3. 增加预览四角 alpha 为零的回归测试，防止颜色再次覆盖背景。

### 迭代结果

- 已将 `.color` 混合裁剪到系统文件夹图标的 alpha 蒙版内。
- 颜色只会改变文件夹本体；预览透明背景保持不变。
- 新增透明背景回归测试，确认渲染图像四角 alpha 为零。
- `swift test` 通过 10 项测试；Xcode GUI App 构建成功。
