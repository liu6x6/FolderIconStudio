# 任务 18：优化左侧栏滚动与层级

## 目标

1. 隐藏左侧栏及其内部区域的滚动条。
2. 限制 Symbol 浏览区域的高度为 320pt。
3. 将预设模板改为 60 x 60pt 图标集合，最多两行十个可见，超出时独立滚动。
4. 强化左栏分区标题与功能内容的视觉层级。

## 实施步骤

1. 使用自定义无指示器滚动容器替换系统侧栏列表。
2. 提取具有图标、强调标题与内容卡片的侧栏分区组件。
3. 为 Symbol 区域和模板集合建立独立的固定高度滚动容器。
4. 用图标缩略图渲染模板，并保留应用与删除操作。

## 验收标准

- 左栏与内部 Symbol/模板区域均不显示滚动条。
- Symbol 区高度为 320pt。
- 模板以 60 x 60pt 图标显示，前十个为两行，更多模板在集合中滚动。
- 标题、说明、主要操作和内容卡片易于区分。

## 完成结果

- 左栏、Symbol 区和模板集合的滚动条均已隐藏。
- Symbol 浏览器已放入 320pt 高度的独立滚动区域。
- 模板以五列 60 x 60pt 缩略图集合显示；前两行可展示十个，更多模板在 136pt 高度的集合中滚动。
- 已新增强调标题和内容卡片的侧栏分区组件，并强化添加图层操作按钮。
- `swift test` 通过 19 项测试，Xcode Debug App 构建成功。
