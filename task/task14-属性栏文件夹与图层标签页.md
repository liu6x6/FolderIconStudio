# 任务 14：属性栏文件夹与图层标签页

## 目标

将右侧属性栏中的文件夹样式和图层编辑分为独立标签页。

## 实施步骤

1. 在属性栏顶部加入分段式标签页选择器。
2. 将底图、颜色、预设颜色和文件夹不透明度放入“文件夹样式”标签。
3. 将图层列表、层级操作和所选图层属性放入“图层”标签。
4. 保留现有无滚动条、贴边的属性栏滚动结构。

## 验收标准

- 可在“文件夹样式”和“图层”间切换。
- 每个标签只显示对应的编辑内容。
- 图层选择、编辑和文件夹颜色功能保持可用。

## 完成结果

- 属性栏顶部已新增“文件夹样式”和“图层”分段标签。
- 文件夹标签包含底图、颜色、预设、取色与不透明度；图层标签包含图层列表、操作和图层属性。
- 右侧栏继续使用原有贴边、隐藏滚动条的滚动容器。
- `swift test` 通过 19 项测试，Xcode Debug App 构建成功。
