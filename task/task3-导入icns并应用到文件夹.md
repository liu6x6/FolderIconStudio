# 任务 3：导入 ICNS 并应用到文件夹

## 目标

让用户将已有的 `.icns` 图标文件直接设置为所选普通文件夹的 Finder 图标，无须重新设计或导出。

## 实施步骤

1. 在 Finder 图标服务中增加 `.icns` 文件校验与图标加载。
2. 复用已有目录校验：目标必须是可写、非应用包、非系统包的本地普通文件夹。
3. 在主工具栏的“应用到 Finder”中添加“应用 ICNS 文件”操作。
4. 使用系统文件选择器仅允许选择 `.icns` 文件；读取失败、格式错误或 Finder 写入失败时展示明确错误。
5. 添加图标文件格式校验测试，并构建 macOS GUI App。

## 使用流程

1. 选择目标文件夹。
2. 点击“应用到 Finder”旁的菜单，选择“应用 ICNS 文件”。
3. 选择一个 `.icns` 文件。
4. 应用成功后，Finder 中该文件夹会显示新图标；可使用“恢复默认”清除它。

## 验收标准

- 用户可以从 GUI 选择并应用有效 `.icns` 文件。
- 非 `.icns` 文件、无法读取的图标和不合法目录均被拒绝并显示原因。
- 成功应用后显示目标文件夹和图标文件名称。
- 恢复默认图标仍然有效。

## 完成结果

- “应用到 Finder”已改为菜单，包含“应用当前设计”和“应用 ICNS 文件”。
- “应用 ICNS 文件”仅允许在目标文件夹已选择时使用，文件选择器仅显示 `.icns`。
- 应用前会再次验证目标文件夹的类型和写入权限；图标扩展名或内容无效时会显示具体错误。
- 成功后会显示 `.icns` 文件名和目标文件夹名称；“恢复默认”仍可清除图标。
- 新增大小写无关的 `.icns` 格式识别测试；`swift test` 通过 11 项测试，Xcode GUI App 构建成功。
