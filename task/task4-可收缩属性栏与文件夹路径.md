# 任务 4：可收缩属性栏与文件夹路径

## 目标

1. 将右侧属性栏改为 macOS 原生 Inspector，可通过工具栏按钮显示或收起。
2. 在当前选中的目标文件夹区域显示完整路径，便于确认操作对象与复制调试。

## 实施步骤

1. 将三栏 `NavigationSplitView` 的右侧详情列替换为 SwiftUI `inspector`。
2. 增加“显示/隐藏属性”工具栏按钮，并保持默认显示。
3. 在左侧当前文件夹区域显示完整 POSIX 路径，允许选择和复制。
4. 构建 GUI App，确认 Inspector 显示、收起与路径布局均可正常使用。

## 验收标准

- 右侧属性栏可通过工具栏按钮收起和重新显示。
- 收起后编辑预览区获得可用宽度。
- 选择文件夹后能看到完整路径，并可以复制。

## 完成结果

- 右侧属性栏已改为 macOS 原生 `Inspector`，默认显示。
- 工具栏新增“显示属性 / 隐藏属性”按钮；收起后预览区自动获得右侧空间。
- 当前文件夹区域显示完整 POSIX 路径，使用等宽字体并支持文本选择与复制。
- `swift test` 通过 11 项测试；Xcode GUI App 构建成功。

## 迭代：修复属性栏约束循环崩溃

1. 移除会触发 AppKit Update Constraints 循环的 SwiftUI `inspector` 修饰器。
2. 使用 `HSplitView` 实现可调整、可收起的右侧属性面板。
3. 保留工具栏开关和完整路径展示。
4. 运行测试和 GUI App 构建，确认启动后不再触发约束循环。

## 迭代：调整属性栏开关位置

1. 将“显示属性 / 隐藏属性”移至尾随的 `primaryAction` 工具栏组。
2. 使其位于该组最右侧，贴合所控制的右侧属性栏。

### 迭代结果

- 属性栏开关已移到尾随 `primaryAction` 工具栏组，并作为最右侧按钮显示。
- Xcode GUI App 构建成功。

## 迭代：恢复左侧资源栏开关

1. 恢复独立的左侧资源栏显示/隐藏状态与左侧工具栏按钮。
2. 保留右侧属性栏独立开关，不替代左侧功能。
3. 形成与 Xcode 一致的左侧资源栏、右侧 Inspector 双收缩控制。
